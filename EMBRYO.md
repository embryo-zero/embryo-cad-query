# Embryo CAD Query

Embryo CAD Query is Embryo-Zero's fork of [CadQuery](https://github.com/CadQuery/cadquery) (aa9f0d7, commit aa9f0d7). It does 3D design written as Python code.

- Our changes live on the `embryo` branch. The original license files (LICENSE) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
